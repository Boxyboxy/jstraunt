## Metadata Contract (SEO-01)

This section replaces a "Component Inventory" for this phase — there are no new rendered components.

### `generateMetadata()` — Event Detail Page

File: `src/app/(guest)/events/[slug]/page.tsx`

The existing page exports no `generateMetadata`. This phase adds it.

#### Title

Pattern: `{event.title} | Palette`

- Uses the root layout `metadata.title.template` already set to `'%s | Palette'`
- Return value: `{ title: event.title }`

Example output: `An Evening of Autumn Flavours | Palette`

#### Description

Pattern: `{event.description}` truncated to 155 characters if longer. Fallback when `event.description` is null or empty:

`A {N}-course tasting menu on {formatted_date} at {venue.name}. Limited to {event.total_seats} guests. Book your seat now.`

Where:
- `{N}` = number of courses (from `courses` relation count)
- `{formatted_date}` = `format(parseISO(event.event_date), 'd MMMM yyyy')` — e.g. "14 June 2026"
- `{venue.name}` = venue name, or "Singapore" if venue is null
- `{event.total_seats}` = integer seat count

Maximum length: 155 characters. Truncate with `…` if over.

#### Open Graph

| Property | Value |
|----------|-------|
| `og:title` | `{event.title} \| Palette` |
| `og:description` | Same as `<meta description>` above |
| `og:type` | `article` |
| `og:image` | `{siteUrl}/og-image.jpg` (static fallback — SEO-02) |
| `og:image:width` | `1200` |
| `og:image:height` | `630` |
| `og:image:alt` | `Palette — Intimate tasting menu experiences in Singapore` |
| `og:url` | `{siteUrl}/events/{event.slug}` |
| `og:site_name` | `Palette` |

`siteUrl` resolved from `process.env.NEXT_PUBLIC_SITE_URL` with fallback `https://palette.sg`.

#### Twitter Card

| Property | Value |
|----------|-------|
| `twitter:card` | `summary_large_image` |
| `twitter:title` | Same as `og:title` |
| `twitter:description` | Same as `<meta description>` |
| `twitter:image` | Same as `og:image` |

#### Next.js `generateMetadata` Return Shape

```ts
return {
  title: event.title,
  description: metaDescription,
  openGraph: {
    title: `${event.title} | Palette`,
    description: metaDescription,
    type: 'article',
    url: `${siteUrl}/events/${event.slug}`,
    siteName: 'Palette',
    images: [
      {
        url: `${siteUrl}/og-image.jpg`,
        width: 1200,
        height: 630,
        alt: 'Palette — Intimate tasting menu experiences in Singapore',
      },
    ],
  },
  twitter: {
    card: 'summary_large_image',
    title: `${event.title} | Palette`,
    description: metaDescription,
    images: [`${siteUrl}/og-image.jpg`],
  },
}
```

#### Not-Found Fallback

When the event is not found (before the `notFound()` call), `generateMetadata` must return a safe fallback:

```ts
return {
  title: 'Event Not Found',
}
```

Do not throw inside `generateMetadata` — catch the Supabase `PGRST116` error and return the fallback title.

### Static OG Image (SEO-02)

No code changes required. Place the OG image file at `/public/og-image.jpg`. The `og:image` URL in `generateMetadata` references it directly via absolute URL.

The image must exist before deployment. If it does not exist, WhatsApp/Telegram previews will show no image (no error thrown, but SEO-02 will be unmet).

### Other Guest Pages

The following guest pages do NOT receive `generateMetadata` in this phase. The root layout provides their fallback title and description:

- `/` (homepage) — root layout default applies
- `/events` (listing page) — root layout default applies
- `/gallery` — root layout default applies

Scope is limited to event detail pages per SEO-01 and SEO-02.
